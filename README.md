# Shenma Live Admin

神马直播后台 App 版本管理交互原型及需求文档，使用 HTML、CSS 和 JavaScript，无需安装依赖或构建。

## 预览

打开 `index.html` 或 `app-version-prototype/index.html`。原型数据保存在当前浏览器的 localStorage 中。

GitHub Pages 地址：https://northpeak2026.github.io/Shenma_Live_Admin/

## 发布

在仓库 Settings → Pages 中选择 Deploy from a branch，分支 `main`，目录 `/(root)`。
根目录入口自动进入 `app-version-prototype/`，并保留查询参数与需求文档 hash 定位。

## 目录

- `app-version-prototype/`：原型源码、需求文档与预览图。

历史页面走查文档、截图与压缩包仅保留在本地，通过 `.gitignore` 排除，不公开发布。
